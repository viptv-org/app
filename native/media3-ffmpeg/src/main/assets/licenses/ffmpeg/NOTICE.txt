Media3 FFmpeg audio decoder

Java/JNI adapter: AndroidX Media3 1.11.1, commit
8c6678b657ede1e7883fc164ef73ed483c7796c3, Apache License 2.0.
Source: https://github.com/androidx/media/tree/1.11.1/libraries/decoder_ffmpeg

Native audio library: FFmpeg 6.0.1, LGPL 2.1 or later, without GPL/nonfree flags.
Source: https://ffmpeg.org/releases/ffmpeg-6.0.1.tar.xz
Source SHA256: 9b16b8731d78e596b4be0d720428ca42df642bb2d78342881ff7f5bc29fc9623
Enabled decoders: aac, mp3, ac3, eac3, dca, truehd, flac, alac, vorbis, opus, amrnb, amrwb, pcm_mulaw, pcm_alaw. No software video decoder is enabled.

Build/relink script: tools/build_media3_audio.py in viptv-org/app.
The script preserves FFmpeg static archives and the JNI wrapper source for
relinking under native/media3-ffmpeg/build/native. Native libraries use API 24,
NDK 28.2.13676358 and 16 KB ELF page alignment for all three shipped ABIs.
Native/source checksums are recorded in native.json and upstream.json.
